## What the next session must know

- **A consumer rehearsal counts only on the candidate's release.** Run it before the manifest, alone, with memory free.
- **A background job that Claude Code "stopped" may still run.** Look for the script and its children before starting anything.
- **An id under a key with "credential", "token" or "key" in its name can turn the secret scan red** when its entropy is high. Name evidence keys without those words.
- **A needle control must be a different string from every argument control** of the same search, and at least 8 bytes.
- **`alerts.staging` takes about 85 minutes.** `probe.staging` is last and alone.
- **`cli.staging` with a published bundle** needs `MYKEY_CLI_DIST` and `MYKEY_CLI_EXPECT`; `automation.staging` refuses a published bundle.
- **`transport.staging` expects production open.** It is red while production is closed for a `--stay-closed` deploy.
