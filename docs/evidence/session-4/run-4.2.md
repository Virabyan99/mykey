## Deviations and decisions

- **The admission recheck is a callback.** `SecretRequest.recheck` is built by the API from `lockParents`, `resolveAccess`, `decide` and `checkStates`, rather than moving `checkStates` into `@mykey/operations`.
- **A throw after the marker.** The protocol answers `outcome_unknown` and tries to record the operation `uncertain` and the key `needs_review` on the main pool. If that fails, the operation stays `executing` for the sweep (Run 4.5). The finish is conditional on the boot id, so an operation that already succeeded is untouched: a throw after finalize answers 503, and the replay answers 201.
- **Suites that used the secret routes as handler-less routes** (`revocation`, `states`, `factors-http`) now stub them by name: a new harness option `stubRoutes` and pipeline flag `test.stubRoutes`. `stubs: "all"` also stubs `organizations.list`, whose real body those suites read. `environments.test.ts`'s write from a renamed environment now expects `503 dependency_unavailable` (that fixture has no runtime identity): the pipeline admitted it.
- **Body shape.** An update without `expectedVersion` or `expectedStateTag`, or with an unknown key, is `400 malformed_request` (Doc 06 §9, `validate.ts`), not the plan's 422.
- **The privilege matrix** names functions by argument types (`oidvectortypes`). `pg_get_function_identity_arguments` includes parameter names, which the restore test saw.
- **D-34 was owed by Task A** and is written in this run, with the staging measurement.
